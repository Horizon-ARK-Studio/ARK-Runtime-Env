## Philosophy

**The codebase should be legible to whoever opens it next, including
a future version of whoever wrote it.** Each directory under `docs/`
keeps its own index (this file, and one per subdirectory) precisely
so a reader never has to already know the layout to find the doc they
need -- see `foundational/README.md` for the fuller version of this
philosophy as it applies to ARE's own foundational docs specifically.
